# 案卷 · Dossier

面向「查清 AI 产品事实、真实使用反馈，以及是否适合某个用途」的前端设计原型。

三块主界面：**搜索首页、调查进行中、调查结果**。证据详情是结果页内的抽屉。首版把「搜索 → 证据 → 原句 → 原始来源」这条链路做完整，而不是做满入口。

## 运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
npm run preview
```

构建后演示画廊在 **`/demo/`**（例如 `http://localhost:4175/demo/`）：13 张关键界面 + 3 分钟演示脚本。源文件在 `demo/`，`postbuild` 会把它复制到 `dist/demo/`。

技术栈：React 19 + Vite + TypeScript + Tailwind CSS v4 + Motion + GSAP + lucide-react。没有引入现成 UI 套件；视觉按参考站重做：Scite 的冷灰白底 + 绿/红/黄证据色，Intern 的白底圆角搜索框，Perplexity 的近黑链路与荧光绿连线。组件原语（引用、标签、图章、抽屉）都在 `src/components/ui.tsx` 里，按需复用。文本动画用 React Bits 的 **FoldText**（`src/components/FoldText.tsx`，改为挂载播放 + 减弱动效），ASCII 波场参考 Asciify 的 **Swell**（`src/components/AsciiField.tsx`，Canvas 实现）。

## 五分钟验收路径

1. 首页点示例 **“DeepSeek API 的上下文长度是多少？”**，看完调查过程，自动进入事实结果。
2. 点正文里的引用角标 **1**：桌面右侧抽屉、移动端底部面板；原句带高亮扫入，可打开原始页面。
3. 关闭证据，焦点与滚动位置回到刚才的引用。
4. 点 **“思考模式的推理过程算输出吗？”**：不发起新调查，直接给基于本次材料的补充回答与引用。
5. 左下 **「样稿」** 面板可跳转其余场景，并开关「网络已断开 / 历史结果」。

| 场景 | 入口 | 可以验证 |
| --- | --- | --- |
| 事实核对 | 示例 1 | 1M / 384K 比较表、来源总览、1 个来源读取受限 |
| 官方声称 vs 实测 | 示例 2 | 支持 / 冲突 / 媒体复核、同源转述合并、两组数字不同题 |
| 按用途评测 | 示例 3 | 用途与条件、有条件值得、8 维能力表、无证据明示 |
| 简短澄清 | 样稿 → 简短澄清 | 对象歧义时先问一个问题，不猜；确认后继续调查 |
| 证据不足 | 样稿 → 证据不足 | 已能确认 / 还不能确定 / 查过哪些来源 |
| 调查失败 | 样稿 → 调查失败 | 可理解的 504 原因、已尝试动作、重试 |
| 离线 / 历史 | 样稿底部开关 | 保留上次内容、调查时间与状态未更新 |

## 设计判断

- **搜索框是唯一入口。** 元宝、条件、粘贴链接、圆形发送收在一行；条件进下拉；示例是三张卡。首屏标题用 FoldText 折叠展开。
- **搜索过程不是步骤条。** 事件按发生顺序追加，可重复搜索、可回补；分支、材料与缺口同时可见。需要看全局时再展开「搜索关系」，节点都能落到实际查询、读取或补查。
- **链路是可见的。** 首页右侧用「说法 → 分支 → 原句 → 结论」示意，调查页展开分支/来源图，结果页证据卡用左侧关系色条接回结论。
- **答案优先。** 结果页先给直接回答，再给表格 / 分歧 / 缺口 / 来源记录。没有冲突时不渲染空的「反对意见」。
- **结果页像证据页。** 顶部是支持 / 冲突 / 尚不能判断 / 读取受限统计，右侧是 Scite 式证据卡（关系色条 + 原句摘要），不是纯链接列表。
- **引用只做一件事：回到原句。** 角标悬停预览，点击打开抽屉；原文、AI 译文、AI 归纳在排版上明确分开；关闭后恢复焦点。
- **来源要能验。** 官方 / 使用者 / 第三方用文字与图标区分；独立来源只在合并同源后计数；「读取受限」「未搜到」「未执行」分开记录。
- **状态不靠颜色。** 关系、来源类型、读取状态都同时有文字或图标。
- **移动端是单列阅读。** 证据改为可拖拽的底部面板；关闭后回到引用位置；表格在局部滚动，页面本身不横移。

## 参考映射

| 参考 | 借用 |
| --- | --- |
| Intern | 搜索框：一体输入、条件下拉、圆形发送 |
| MindSearch | 子问题分支、多路搜索、可展开的关系视图 |
| Gemini Deep Research | 来源→结论的汇聚、研究随材料调整、当前动作与已读材料同屏 |
| Perplexity Deep Research | 分支查询、结构化研究、把过程压缩为状态 |
| NotebookLM | 点击/悬停引用、原句高亮、回到来源 |
| Scite | 统计徽章 + 支持 / 冲突 / 尚不能判断的证据卡 |
| Exa Websets | 来源总览表：站点、版本、发布时间、读取状态、上游 |
| React Bits FoldText / Asciify Swell | 首屏纸折标题 / 链路与关系图的 ASCII 波场 |

搜索关系图默认收起，不挡答案；更复杂的图不作为阅读前提。

```text
  data/scenarios.ts      五个可出结果的调查 + 失败状态：事件、证据、结论、图谱、首页归档

  components/
    HomeScreen.tsx       首页、搜索框、示例、归档、链路
    ChainPreview.tsx     说法 → 分支 → 原句 → 结论
    FoldText.tsx         React Bits FoldText 适配
    AsciiField.tsx       Asciify Swell 风格 ASCII 波场
    InvestigatingScreen  实时活动、分支、材料、澄清、成卷动效
    ResultScreen         结果头、统计徽章、横幅、阅读栏、进度
    ResultSections       结论卡、表格、分歧、能力、来源、追问、证据卡
    EvidencePanel        证据抽屉 / 底部面板

    DemoPanel            样稿控制

```

## 数据与边界

- 所有数字、引文、结论与社区反馈都是**设计样稿**，结果页有「样稿」标记；正式演示前必须替换为真实调查结果。
- 来源链接指向可打开的公开页面；引文为样稿，不应当作真实抓取结果引用。
- 没有接入实时搜索。未知问题不会生成假答案，只会提示样稿范围；已知问题按脚本回放，事件间隔被压缩。
- 不显示模型内部思考、百分比或预计剩余时间。
- 收藏、账户、热度、复杂筛选不在首版范围内。

## 已验证

- `npx tsc -b`、`npm run build` 通过；`npm run lint` 无错误（4 条 React `set-state-in-effect` 警告，属于抽屉重置与调查状态机的有意副作用）。
- Chrome 1440×1000 与 390×844 两种视口：无页面级横向溢出；移动端证据为底部面板；关系图的宽画布只在自身容器内滚动。
- 交互链路：提问 → 调查 → 结果 → 引用 → 原句 → 原始来源；Esc 分层关闭证据 / 关系图；关闭证据恢复引用焦点与滚动位置。
